# EZConnect research

- `analysis/` contains the existing decoded constants, bytecode and disassembly evidence, reconstructed settings, and investigation notes. Start with `analysis/RECONSTRUCTION.md`.
- `audits/` contains the existing route and handshake audit reports.
- `reference/` contains the Nuitka source reference used during the extraction work.

The archive contains partial reconstruction and extracted evidence. The original EZConnect source tree was never recovered. The raw files stay local and are excluded from Git and RouteFinder releases.
